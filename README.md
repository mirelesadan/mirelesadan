# Hi, I’m Adan Mireles 👋

I’m an **Applied Physics PhD candidate at Rice University**, materials scientist, and scientific software developer working at the intersection of **microscopy, computational physics, machine learning, and high-performance computing**.

I’m interested in optimizing scientific and engineering workflows—from raw experimental data to validated, reusable software—using numerical methods, AI, and GPU computing.

## 🔬 What I’m building

* **[4Denoise](https://github.com/mirelesadan/4denoise)**
  An open-source Python package for processing, denoising, and visualizing 4D-STEM datasets. It supports Bragg-peak analysis, crystallographic tilt inference, 3D topography reconstruction, tilt-corrected strain mapping, and interactive visualization.

* **Generalized C-MEP** *(coming soon)*
  A reusable workflow for combining orthogonal multislice electron ptychography datasets into registered 3D intensity volumes, forming the basis for atomic-position inference at buried material interfaces.

* **CUDA C++ Performance Engineering** *(in active development)*
  A portfolio of scientific-computing kernels progressing from Python references to C++, CPU-optimized C++, CUDA C++, and Python interfaces, with an emphasis on correctness, profiling, benchmarking, and transparent performance analysis.

* **[Reinforcement Learning Control of a Double Pendulum](https://github.com/mirelesadan/reinforcement)**
  A physics-based continuous-control project featuring symbolically derived nonlinear equations of motion, custom Gym environments, and Stable-Baselines3 agents trained to control a double pendulum on a cart.

## 🤖 How I work with AI

I’m strongly pro-AI and believe **agentic coding will become a standard part of scientific and engineering software development**.

I use Codex and GPT-based agents to decompose technical problems, explore implementations, refactor code, develop tests, debug workflows, and improve documentation. I provide the relevant physical assumptions and numerical constraints, review the resulting code, and remain responsible for validation, reproducibility, and scientific correctness.
