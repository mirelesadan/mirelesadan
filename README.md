# Hi, I’m Adan Mireles 👋

I’m an **Applied Physics PhD candidate at Rice University**, materials scientist, and scientific software developer working at the intersection of **microscopy, computational physics, machine learning, and high-performance computing**.

I turn complex scientific problems into validated, reusable computational workflows—from multidimensional experimental data and physics-based simulations to optimized native implementations and interactive visualization.

## 🔬 Featured projects

* **[4Denoise](https://github.com/mirelesadan/4denoise)**
  An open-source Python package for processing and visualizing 4D-STEM data. It supports preprocessing, Bragg-peak analysis, crystallographic tilt inference, 3D topography reconstruction, tilt-corrected strain mapping, and interactive visualization. The package supports my first-author *Science Advances* study, [“Strain Mapping of Three-Dimensionally Structured Two-Dimensional Materials”](https://doi.org/10.1126/sciadv.adz7908).

* **[Generalized C-MEP](https://github.com/mirelesadan/generalized-CMEP)**
  A reusable Python workflow for correlative multislice electron ptychography, including physical orientation of 3D volumes, registration of orthogonal datasets, likelihood-score mapping, subvoxel atom localization, and simulation-based validation with ASE and abTEM.

* **[CUDA C++ Performance Engineering](https://github.com/mirelesadan/CUDA-Cpp-Performance-Engineering)** *(in active development)*
  A correctness-first portfolio translating scientific Python workloads into C++ and CUDA C++. The current implementation progresses from a validated Python reference to C++17, profiled serial optimizations, and OpenMP scaling. Its first benchmark processes more than 47 million median-filter outputs and reaches an 8.73× multicore speedup while matching the reference output bit for bit. CUDA kernels, GPU profiling, and Python bindings are the next development stages.

* **[Reinforcement Learning Control of a Double Pendulum](https://github.com/mirelesadan/double-pendulum-rl-control)**
  A continuous-control project built from symbolically derived nonlinear equations of motion, custom Gym environments, and Stable-Baselines3 DDPG agents trained to control a double pendulum on a cart.

## 🤖 How I work with AI

I’m strongly pro-AI and believe **agentic coding will become a standard part of scientific and engineering software development**.

I use Codex and GPT-based agents as engineering collaborators: I decompose research problems into bounded implementation tasks, define the physical assumptions and numerical contracts, and use agents to explore implementations, refactor code, develop tests, debug workflows, and improve documentation. I review the resulting code and remain responsible for software architecture, validation, reproducibility, and scientific correctness.
